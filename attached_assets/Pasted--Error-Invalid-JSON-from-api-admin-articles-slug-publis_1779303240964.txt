
Error: Invalid JSON from /api/admin/articles/{slug}/publish
هذا يعني أن الـ API يرجع HTML بدل JSON — وهذا يحدث لأن:

الـ API middleware موجود فقط في Vite dev server — عندما تفتح الصفحة في المتصفح، الطلب يذهب لـ Vite، لكن Vite يرجع صفحة HTML (SPA fallback) بدل تشغيل الـ API route
السبب الجذري: المشروع على Replit، وعند الضغط على Publish تذهب لـ /api/admin/articles/.../publish لكن Vite لا يعالج هذا الـ route إذا كان الـ dev server لم يبدأ بشكل صحيح أو أن هناك مشكلة في المنفذ

الخطوة 3: الإصلاح الحقيقي — أضف هذا الكود في vite.config.ts
المشكلة الأساسية أن الـ middleware يحتاج أن يعمل قبل أي middleware آخر. ابحث عن:

  return {
    name: "admin-api",

وتأكد أن الترتيب هكذا — الـ JSON headers تُضبط قبل أي شيء:
typescriptfunction adminApiPlugin(): Plugin {
  return {
    name: "admin-api",
    configureServer(server) {
      // أضف هذا الـ middleware في البداية - يمنع Vite من إرجاع HTML للـ API routes
      server.middlewares.use((req, res, next) => {
        if (req.url?.startsWith("/api/admin")) {
          res.setHeader("Content-Type", "application/json");
          res.setHeader("Cache-Control", "no-store");
        }
        next();
      });
