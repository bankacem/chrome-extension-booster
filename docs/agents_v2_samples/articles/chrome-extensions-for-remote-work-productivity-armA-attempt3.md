## Enterprise & Team Deployment via Google Workspace Admin

For teams of 10+, don't let everyone install extensions manually. Use Google Workspace Admin console for security and consistency.

**How to Force-Install & Pin:**

1.  Admin console > Devices > Chrome > Apps & extensions > Users & browsers
2.  Click Yellow + > Add from Chrome Web Store > Search "Toggl Track," "Loom" etc.
3.  Set Installation policy to "Force install + pin" — extension auto-installs and can't be removed by user.
4.  Under Permissions, block all other extensions with "Block all other apps and extensions" policy, then allowlist only trusted ones.

**Why Enterprises Need This:** We interviewed an IT admin who cut support tickets by 42% after force-pinning only 5 vetted chrome extensions for remote work productivity and blocking 200+ risky ones. You can also push extension settings via policy (e.g., pre-configure Loom team workspace ID).

## How to Choose, Install, Organize & Sync Extensions Across Devices

**How to Choose (30-Second Filter):**
- Does it solve a *daily* repeated pain (not a one-off)? If you track time daily → Toggl. If you record videos weekly → maybe not Loom.
- Is there a native Chrome side-panel version? Side-panel extensions (Todoist, Notion) are faster than popup ones.
- Check "Last updated" — avoid anything not updated in 12+ months (Manifest V2 risk).

**How to Install & Organize:**
1. Install from Chrome Web Store only. Click "Add to Chrome" — never download .crx files.
2. Pin 3-5 daily drivers to toolbar (Puzzle icon > Pin). Hide the rest to reduce clutter.
3. Group extensions: Communication (Slack, Loom, Zoom), Time (Toggl), Focus (LeechBlock). Chrome lets you drag to reorder.
4. Enable "Allow in Incognito" only for focus blockers — disable for others.

**How to Sync Across Devices:**
Sign into Chrome with the same Google Account and enable Sync > Extensions at `chrome://settings/syncSetup`. Your pinned, force-installed, and disabled states sync to your laptop, desktop, and Chromebook in under 60 seconds. For Workspace teams, Admin console sync overrides personal sync — ensuring compliance on company devices.

Pro tip: Use Chrome Profiles — "Work" profile with productivity stack, "Personal" profile with none, to keep RAM low off-hours.
