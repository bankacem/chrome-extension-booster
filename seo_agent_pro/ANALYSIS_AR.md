# تحليل وكيل SEO Agent Pro (التوثيق الداخلي)

هذا المستند يقدم شرحاً تفصيلياً لوكيل الذكاء الاصطناعي `seo_agent_pro` الموجود في المشروع.

---

## 1. نظرة عامة
**SEO Agent Pro** هو نظام خبير مؤتمت بالكامل لإدارة وصناعة المحتوى المتوافق مع محركات البحث. يعتمد على هندسة "الوكلاء المتعددين" (Agentic Workflow) حيث يتم تقسيم المهام المعقدة إلى وحدات صغيرة متخصصة.

## 2. الهيكل البرمجي (Architecture)

### أ. إدارة النماذج اللغوية (`llm_router.py` & `config.py`)
- **دعم متعدد:** يتصل بـ Anthropic, Groq, و OpenRouter.
- **المرونة:** يمكن تبديل "العقل" المحرك للوكيل بسهولة بين نماذج مثل Claude 3.5, GPT-4o, و DeepSeek.
- **التنسيق:** يضمن خروج البيانات بتنسيق JSON نظيف لاستخدامه في مراحل الـ Pipeline التالية.

### ب. خط الإنتاج ذو الـ 8 مراحل (`modules.py`)
يعمل الوكيل عبر 8 وحدات برمجية مستقلة:
1.  **تحليل المنافسين:** اكتشاف الثغرات في محتوى الخصوم.
2.  **الاستراتيجية:** تحديد الطول، النوع، والزاوية الفريدة للمقال.
3.  **الكتابة:** إنتاج محتوى طويل عالي الجودة مع التركيز على "Information Gain".
4.  **تحسين الـ CTR:** صناعة عناوين ووصف ميتا جذاب.
5.  **العناقيد (Clusters):** بناء خارطة للمواضيع المرتبطة لبناء سلطة موضوعية.
6.  **الجدول الزمني:** تخطيط المحتوى لمدة 3 أشهر مقدماً.
7.  **درجة السلطة (Authority):** تقييم مدى تغطية الموقع لمجاله.
8.  **تحديث الذاكرة:** حفظ النتائج للتعلم المستقبلي.

### ج. نظام الذاكرة المستمرة (`memory.py`)
- يحفظ البيانات في `seo_memory.json`.
- يتتبع المقالات التي تمت كتابتها لمنع التكرار (Keyword Cannibalization).
- يراقب تطور "السلطة الموضوعية" للموقع بمرور الوقت.

## 3. أوضاع التشغيل (Run Modes)
- `full`: تشغيل الدورة الكاملة من البحث حتى الجدولة.
- `article`: إنتاج مقال واحد فقط بسرعة.
- `cluster`: إنشاء خارطة مواضيع وكلمات مفتاحية مرتبطة.
- `calendar`: توليد خطة نشر فقط.

## 4. المخرجات
يتم حفظ جميع النتائج في مجلد `output/` بصيغتين:
- **Markdown (.md):** المقالات جاهزة للنشر مع الـ Frontmatter.
- **JSON:** التقارير التحليلية والخرائط الذهنية وجداول المحتوى.
