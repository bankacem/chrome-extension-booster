If you rely on the keyboard to move through pages, copy passages, or open links without a mouse, Chrome already includes options that help. This guide starts with built‑in controls—especially Caret Browsing—then shows where a few Google‑listed extensions improve visibility and access for reading.

## Start with Chrome’s built‑in keyboard navigation

Before adding anything, try the shortcuts Chrome supports by default (availability can vary by device and OS):

- Tab / Shift+Tab: move focus forward or backward through links, buttons, and fields.
- Enter: activate the focused item.
- Space or Page Down: scroll down; Shift+Space or Page Up: scroll up.
- Ctrl/⌘+F: Find in page to jump directly to words you care about.

Chrome’s official list covers many more time‑savers that reduce pointer reach while browsing: see [Chrome keyboard shortcuts](https://support.google.com/chrome/answer/157179?hl=en). These basics are often enough to navigate controls and jump around long pages efficiently.

### Caret Browsing: read and select text with the keyboard

When you want to move a text cursor through a webpage as if it were a document—character by character or line by line—use Caret Browsing. Chrome Help documents that you can toggle it with F7 and move the caret with the arrow keys; hold Shift with the arrows to select text. Press F7 again to turn it off. On some laptops and Macs, you may need to hold Fn while pressing F7, depending on keyboard settings. The first time you press F7, Chrome typically shows a prompt asking to enable Caret Browsing. If nothing appears, try Fn+F7 or check whether another app is intercepting function keys.

With Caret Browsing on, you can:
- Move carefully through paragraphs to read at your pace.
- Select exactly what you want to copy using Shift+Arrow.
- Open a link by placing the caret on it and pressing Enter.

## Match the task to the right tool

Start with built‑in features; add an extension only when it solves a specific problem. The options below are curated from Chrome’s Help pages:

- Goal: Move and select text by keyboard
  - Start with: Caret Browsing (F7)
  - If you still need help: A Caret Browsing extension listed by Chrome Help can offer similar behavior when F7 isn’t available in your environment.

- Goal: Improve text/background legibility while reading
  - Start with: Page zoom and default font size in Chrome settings
  - If you still need help: High Contrast (applies contrast/inversion schemes)

- Goal: Distinguish similar colors (e.g., in charts, maps, or link sets)
  - Start with: Page zoom and site styles
  - If you still need help: Color Enhancer (adjustable color filter)

- Goal: Open detailed image descriptions when provided
  - Start with: Visible captions/alt text on the page
  - If you still need help: Long Descriptions (exposes longdesc when sites include it)

Note: Extension names above are taken from Google’s Chrome Help list of accessibility tools. Exact behavior and options are defined by their publishers; review each listing before installing.

## How to use each option effectively

### Caret Browsing (built‑in and extension)
- Toggle: Press F7 (use Fn+F7 on some keyboards). When on, the caret appears within page text. See [Browse web pages with Caret Browsing (Chrome Help)](https://support.google.com/chrome/answer/10181515?hl=en).
- Navigate: Arrow keys move the caret; Shift+Arrow selects text. Press Enter on a link to open it.
- If F7 is blocked: See Troubleshooting below. When your setup prevents function keys, Chrome Help also points to a Caret Browsing extension that provides similar functionality.

### High Contrast (extension)
- What it does: Applies high‑contrast or inverted color schemes that can make text stand out against backgrounds.
- When to use: If standard zoom and font settings aren’t enough and you need stronger separation between text and background while tabbing and reading.
- Tip: Toggle from the extension’s toolbar button when a site’s own dark mode or readable theme is sufficient.

### Color Enhancer (extension)
- What it does: Adds an adjustable color filter intended to improve the distinction of similar hues.
- When to use: On charts, maps, or UIs where red/green or other close colors are hard to tell apart.
- Tip: Calibrate the filter so it helps on data‑heavy pages without overwhelming body text.

### Long Descriptions (extension)
- What it does: Surfaces long descriptions when a site provides them using supported markup (for example, the longdesc attribute referenced by Chrome Help). It does not generate descriptions.
- When to use: For images where a visible caption isn’t enough and you want the author’s extended description, if available.

## Reading workflow tips that minimize the mouse

- Combine Find in page with Caret Browsing: Use Ctrl/⌘+F to jump to a keyword, then enable Caret Browsing to read the nearby paragraph line by line.
- Switch between focus and caret as needed: Use Tab to hop to buttons or fields; turn on Caret Browsing for precise text selection; turn it off to resume quick focus navigation.
- Open links in context: With Caret Browsing on, place the caret on a link and press Enter. For research sessions, pair these habits with the organizational ideas in our [student productivity stack](/blog/pro-student-chrome-extensions-the-ultimate-academic-stack) to keep sources tidy.
- Adjust zoom per site: Increase page zoom on dense sites to reduce eye strain before turning to color or contrast filters.

## Troubleshooting

- F7 does nothing or no prompt appears
  - Try Fn+F7 (some keyboards set function keys to media controls by default).
  - Close or disable apps that capture function keys globally (for example, system utilities), then try again.
  - Temporarily disable other extensions that modify keyboard input, test F7, then re‑enable one by one.

- The caret moves, but links don’t open with Enter
  - Confirm the caret is visibly on the link text. If the site relies on custom scripts, press Tab to focus the link instead, then press Enter.

- Focus outline is hard to see when tabbing
  - Increase zoom and consider High Contrast for stronger outlines. Some sites customize focus styles; High Contrast can make them more visible.

- Visual changes don’t appear on some elements
  - High Contrast and Color Enhancer alter page rendering, but videos, canvas content, or images with baked‑in low contrast may remain difficult to see.

- Keyboard navigation seems trapped in a section
  - Single‑page apps sometimes capture focus. Press Esc, then Tab to continue. If needed, reload the page to reset focus.

## Limitations to keep in mind

- Caret Browsing works with selectable text. Complex controls, embedded widgets, or canvas‑based content may not behave like document text.
- High Contrast and Color Enhancer change how pages render, which may reduce color accuracy for images or brand colors. Toggle them off when reviewing color‑critical content.
- Long Descriptions only reveals author‑provided descriptions; it doesn’t create alternate text.
- Websites can define their own keyboard shortcuts or scripts that override expectations; results can vary by site.
- Platform differences: The exact key to toggle Caret Browsing can vary by device and keyboard configuration. If F7 is unavailable, Chrome Help lists an extension alternative.

## FAQ

- How do I toggle Caret Browsing in Chrome?
  - Press F7 to toggle it. If nothing happens, try Fn+F7. A confirmation prompt usually appears the first time.

- What’s the difference between Tab navigation and Caret Browsing?
  - Tab jumps focus among interactive elements; Caret Browsing places a text cursor in page content so you can move and select text with arrows.

- Do I need a screen reader to benefit from these tools?
  - No. These options assist keyboard navigation and reading even without a screen reader. If you do use a screen reader, test carefully—some shortcuts may overlap.

- Will these options work the same on Windows, Mac, and Chromebooks?
  - Chrome Help documents them across platforms, but keys and behavior can vary by device and keyboard settings. Test on your setup and adjust accordingly.
