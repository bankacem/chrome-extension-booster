  <li><strong>Update your browser</strong>: Make sure you're running the latest version of Chrome. You can check for updates by typing <code>chrome://version</code> in the address bar.</li>
  <li><strong>Use a tab suspender</strong>: If you have too many tabs open at the same time, consider using a tab suspender like <a href="/extension/protab-suspender" class="text-primary font-medium hover:underline">ProTab Suspender</a> to suspend inactive tabs and free up memory.</li>

</ol>
