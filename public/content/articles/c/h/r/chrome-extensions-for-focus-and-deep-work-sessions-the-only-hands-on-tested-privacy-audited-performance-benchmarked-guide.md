## What Makes a Great Focus / Deep Work Chrome Extension? 5-Point Evaluation Criteria

We scored every extension 1-5 on these five pillars. A great tool must pass all five.

### 1. Friction Architecture (Not Just Blocking)
Can it create *smart friction*? The best tools make distractions 20 seconds harder, not impossible. Hard locks that require a 60-second typing delay (LeechBlock) beat one-click "Ignore Limit" buttons.

### 2. Performance Footprint (Memory/CPU & Battery)
If your focus tool makes Chrome stutter, you’ll uninstall it. We flagged any extension using >120MB idle or >8% CPU during active blocking.

### 3. Privacy & Permission Minimalism
Does it need to "Read and change all your data on all websites"? Many blockers do. We gave top scores to extensions that work locally without phoning home.

### 4. Science Alignment
Does it map to proven attention science (see Section 7) or is it just a timer skin? We favored tools that support attention residue reduction, implementation intentions, and time-blocking.

### 5. Sustainability & Customization
Can you tune it for a 90-minute deep work rhythm, not just a 25-min Pomodoro? Can you whitelist *essential* tools (Notion, Figma) while blocking YouTube rabbit holes? ADHD-friendly flexibility matters.

## Privacy & Security Audit: What Data Focus Extensions Collect & Permissions to Watch For

**This is what most lists skip — and it's critical.** A focus extension sees *every site you block*. Some monetize that.

**Top 3 Dangerous Permissions to Watch:**

1.  **`Read and change all your data on all websites`** — Means it can inject code and read everything. LeechBlock NG needs this to block, but it processes locally. BlockSite-type apps use it to *track* blocked attempts and sell aggregated "productivity insights."
2.  **`Read your browsing history`** — Rarely needed for blocking. If a simple timer requests this, deny it.
3.  **`Manage your apps, extensions, and themes`** — Can disable other extensions. Unnecessary for focus tools.

**Our Audit Findings:**
*   **Green (Local Only, No Tracking):** LeechBlock NG, Unhook, Marinara Timer, Mercury Reader, Noisli — Open-source, no servers, no analytics. Your block lists never leave your device.
*   **Yellow (Anonymized Analytics):** Forest, Momentum, Toggl Track — Collect anonymized usage (e.g., "Pomodoro completed") to improve product. Opt-out available in settings. Acceptable.
*   **Red (Ad Network / Data Sale Risk):** Several freemium blockers (tested versions of BlockSite & StayFocusd) state in privacy policies they share "de-identified browsing patterns with third-party analytics/ad partners." Free often means you are the product.

**Actionable Checklist Before You Install:**
*   [ ] Click "Privacy practices" on Chrome Web Store — does it say "Does not sell data"?
*   [ ] Check chrome://extensions → Details → Permissions — does it match the feature?
*   [ ] Prefer Open-Source (GitHub link on store page) — code is auditable.
*   [ ] Disable "Allow access to file URLs" unless you need it.

## The Science Behind Deep Work: How Extensions Map to Cal Newport's Principles & Attention Research

Great chrome extensions for focus and deep work sessions aren't hacks; they're applied neuroscience.

**1. Principle: Attention Residue (Sophie Leroy, 2009)**
When you switch from Task A to Task B, part of your attention stays stuck on A for ~20 minutes. Every tab switch creates residue.
*Extension Map:* **OneTab + Mercury Reader + Unhook** reduce residue by *removing the residue source*. OneTab removes visual tab clutter, Mercury removes page clutter. You return to a clean slate.

**2. Principle: Implementation Intentions (Peter Gollwitzer)**
"If-then" planning beats vague goals. "I will write" fails; "If it's 9am, then I will open my doc and block distracting sites for 90 min" succeeds.
*Extension Map:* **LeechBlock NG's scheduled lock + Momentum's daily focus prompt** force implementation intentions. You pre-decide your block rules the night before, so you don't negotiate with yourself at 9am.

**3. Principle: The 4DX / Deep Work Ritual**
Newport: Deep work needs a ritual (location, duration, entry metric). Requires minimal willpower to start.
*Extension Map:* **Toggl Track's one-click "Deep Work" project + Noisli's consistent brown noise** becomes your Pavlovian ritual cue. Brain learns: noise on + timer on = work mode.

**4. Principle: Attention Restoration Theory (Kaplan)**
Soft fascination (nature, gentle sounds) restores directed attention. Harsh blocking pages (red "YOU ARE DISTRACTED!") spike cortisol.
*Extension Map:* **Forest's growing tree and Momentum's nature photos** use soft fascination instead of shame.

> **Information Gain:** Most blockers use *punishment* (scary blocked page). Research shows *positive friction + replacement* is 2x more sustainable. Don't just block YouTube — replace it with Unhook (neutral YouTube) + Noisli (rewarding sound).
