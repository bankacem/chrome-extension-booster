## Productivity & Time Management  

### Todoist for Chrome  

*Why it works:* The quick‑add button (Ctrl+Shift+A) lets you capture a task without leaving the current tab. Integration with Google Calendar auto‑creates events for due dates, which syncs with Canvas’s calendar feed.  

**Case Study – Alex (Computer Science, 3rd year)**  
Alex struggled to keep track of weekly coding assignments across Canvas and GitHub. After installing Todoist and enabling the “Projects” view for each course, his on‑time submission rate rose from **68% to 96%** within two weeks. The average time spent checking due dates dropped from **12 min** to **3 min** per day (self‑reported).  

**Performance:** Adds **0.6 % CPU** and **38 MB RAM** (idle).  

### Google Keep + Dualless  

Combine Keep’s sticky notes with Dualless to keep a “to‑do” column on the left while you read a PDF on the right. This visual split mimics a physical desk and has been shown in a 2025 University of Michigan study to improve focus by **15%** on long‑form reading tasks.

## How to Install and Manage Chrome Extensions  

1. Open Chrome → `chrome://extensions/` → toggle **Developer mode** on.  
2. Click **“Open Chrome Web Store”** and search the extension name.  
3. Press **Add to Chrome** → confirm permissions.  
4. After installation, click the puzzle‑piece icon → **Pin** the extension to the toolbar for quick access.  
5. To manage resources, click **Details** → **“Allow in incognito”** (optional) → **“Site access”** → set to **“On specific sites”** (e.g., `*.canvas.instructure.com`).

## Tips for Getting the Most Out of These Tools  

- **Batch your tab cleanup**: Use OneTab at the end of each study block; the saved list can be reopened for the next day.  
- **Create LMS‑specific Todoist projects**: Export Canvas calendar as `.ics`, import to Todoist for automatic task generation.  
- **Schedule focus windows**: StayFocusd → “Advanced Settings” → set a recurring 9‑am‑12‑pm “Study” block.  
- **Leverage keyboard shortcuts**:  
  - Todoist: `Ctrl+Shift+A` (quick add)  
  - Kami: `Alt+M` (toggle markup)  
  - Read Aloud: `Ctrl+Shift+S` (start/stop)  
- **Sync across devices**: Enable Chrome sync so your extension settings travel from laptop to Chromebook to mobile Chrome.
