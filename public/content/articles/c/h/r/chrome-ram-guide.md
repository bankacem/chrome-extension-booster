## Why Chrome Uses So Much RAM
Chrome uses a "process-per-site" architecture to ensure that if one tab crashes, the whole browser doesn't go down with it. While this increases stability and security, it comes at the cost of higher memory consumption.

## Optimization Tips
1. **Enable Memory Saver Mode:** Built directly into Chrome, this feature frees up memory from inactive tabs.
2. **Use Tab Suspenders:** Extensions like ProTab Suspender can automatically hibernate tabs you aren't using.
3. **Limit Extensions:** Every extension is a new process. Only keep the ones you truly need.
