## What is BetterTTV for Chrome?

BetterTTV (often abbreviated as BTTV) is a free browser extension created by [NightDev][1] to enhance the viewing and chat experience on Twitch. It does so by introducing features that improve customization, accessibility, and usability when interacting with Twitch streams. Popular additions include enhanced emote options, chat customizations, and visual tweaks like better dark mode support.

BetterTTV isn’t just for Twitch—it also offers functionality for **YouTube live chats**, making it useful for fans of live video content across platforms.

## Installing BetterTTV on Google Chrome

Installing BetterTTV on Chrome is straightforward. Follow these steps:

### Step 1: Access the BetterTTV Extension
Go to the [official BetterTTV website][1] and click **"Download for Chrome"**. This link will direct you to the [official Chrome Web Store listing][2] for BetterTTV. Alternatively, you can navigate straight to the Chrome Web Store and search for "BetterTTV."

### Step 2: Install the Extension
1. Click **"Add to Chrome."**
2. When prompted, confirm the action by selecting **"Add Extension."**

Once installed, the BetterTTV icon will appear in your browser's extension toolbar. If you don’t see it, check your Chrome extensions menu and pin it for easier access.

### Step 3: Configure BetterTTV on Twitch
1. Navigate to [Twitch.tv](https://www.twitch.tv/) and log into your account.
2. Click your profile icon in the top-right corner and select **Settings.**
3. Scroll down to find the new **BetterTTV Settings** section.
4. Here, enable specific features like dark mode, emotes, or chat customizations to tailor your streaming experience.

That’s it! BetterTTV is now ready to use.

## BetterTTV Features for Twitch and YouTube Users

BetterTTV significantly enhances the functionality of Twitch and expands to provide added features for live streaming on YouTube. Here’s a look at some of its core functionalities:

### Twitch-Specific Features

| **Feature**               | **Purpose**                                                                                   |
|----------------------------|-----------------------------------------------------------------------------------------------|
| **Emotes**                | Access exclusive emotes, including global BTTV and custom channel-specific emotes.            |
| **Dark Mode**             | Enhanced readability for nighttime viewings with a Twitch-optimized dark theme.              |
| **Auto-Chat Reconnect**   | Automatically reconnects to chat during stream interruptions.                                |
| **Chat Filters**          | Block specific keywords or phrases for a cleaner chat experience.                            |
| **Deleted Messages View** | See deleted messages with the option to enable or disable this feature in settings.          |
| **Pinned Emotes Menu**    | Easily access and use a dedicated menu for BTTV emotes in live streams.                      |
| **Anonymous Mode**        | View streams without a visible chat presence, ideal for lurkers.                            |

### YouTube Support
While BetterTTV was initially developed for Twitch, recent updates introduced support for YouTube live chat. This extension offers a selection of its features—such as additional emotes and chat customizations—on YouTube's live-streaming interface as well. Keep in mind that not all Twitch-specific features will apply to YouTube, given the differences in platform architecture.

## Free vs. BetterTTV Pro Features

BetterTTV is free to use, but an optional **Pro tier** unlocks premium features. Here’s how the free and Pro versions compare:

| **Feature**                        | **Free**                             | **Pro**                                            |
|------------------------------------|---------------------------------------|---------------------------------------------------|
| **Emotes**                         | Access global and channel-specific BTTV emotes. | Upload and use **personal/custom emotes**.        |
| **Dark Mode and Chat Features**    | Fully supported.                      | Same as Free.                                      |
| **Ad-Free Experience (BTTV site)** | -                                     | Access BetterTTV website with no ads.            |
| **Priority Support**               | -                                     | Get direct support from the BetterTTV team.      |

BetterTTV Pro subscriptions are optional, and they primarily cater to users looking to personalize their emote usage further.

## Privacy and Permissions

### Privacy Considerations
According to [BetterTTV’s Privacy Policy][1], the extension collects minimal user data to support its functionality, such as settings preferences. Importantly:

- **User chats** are not logged.
- Information is not used for advertising or sold to third parties.

However, users should install BetterTTV **only** from the official sources ([betterttv.com][1] or [Chrome Web Store][2]) to avoid malicious clones that could breach privacy.

### Permissions
When installing BetterTTV on Chrome, you’ll be asked to grant it the ability to modify Twitch and YouTube content. This is necessary for enabling its features but does not allow the extension to access unrelated browsing data or private information across other websites.

## Disabling or Adjusting BetterTTV Features

If you ever need to disable a specific functionality (e.g., chat alterations), follow these steps:

1. Go to Twitch and log in.
2. Click your profile icon in the top-right corner, then navigate to **Settings > BetterTTV Settings.**
3. Toggle off features like "Emotes," "Dark Mode," or others you no longer wish to use.

To completely remove the extension, open Chrome’s **Extensions** menu (chrome://extensions/), find BetterTTV, and click **Remove.**

## Common Issues and Troubleshooting

### BetterTTV Features Not Working
- **Fix**: Ensure the extension is enabled and active. Refresh the Twitch or YouTube page. Check for possible conflicts with other extensions, such as ad blockers or theme customizers.

### Emotes Aren’t Displaying
- **Fix**: Confirm that emotes are enabled in the BTTV settings panel. If the problem persists, clear your browser cache or disable and re-enable the extension.

### Performance Issues (Lagging or Freezing)
- **Fix**: Disable unneeded features in BTTV’s settings. Ensure your Chrome browser is updated to the latest version, and close unused background applications or tabs.

## FAQ

**Q: Is BetterTTV compatible with other extensions like FrankerFaceZ or 7TV?**
A: Yes, BetterTTV can complement other popular Twitch-related extensions like FrankerFaceZ and 7TV. However, other extensions like ad blockers or dark mode/theme tools may interfere, so adjustments might be needed.

**Q: Does BetterTTV work on platforms other than Twitch?**
A: Yes, BetterTTV provides limited support for YouTube live chat. Currently, not all Twitch-specific features are available on YouTube.

**Q: Can I use my BetterTTV settings across multiple devices?**
A: Yes, BetterTTV allows you to sync your settings across devices if you choose to create an account. This feature also lets you upload and manage personal emotes if you’re a Pro user.
