Google Dictionary (by Google) is a long-standing Chrome extension that brings quick, inline definitions to the pages you already read. This guide focuses on installing it correctly, using its double‑click and toolbar lookups, understanding its optional word history, and resolving common issues—especially the “nothing happens after install” problem that often confuses first‑time users.

## What the extension does, according to its listing
The Chrome Web Store listing for Google Dictionary (by Google) describes a few core capabilities you can expect:
- Double‑click a word on a web page to see a brief definition in a pop‑up bubble.
- Use the browser toolbar icon to look up any word without leaving your tab.
- Optionally keep a history of words you’ve looked up.
- Translate foreign words into your language within the same pop‑up.
- Reloading tabs opened before installation may be needed for the pop‑up to work (as noted on the listing).

All of the points above are described or implied on the extension’s official Chrome Web Store page. Because the feature set can evolve, treat these as publisher-stated capabilities rather than guaranteed behavior on every site or configuration.

## Install it safely and avoid early missteps
You can add the extension from its official listing on the Chrome Web Store. Chrome will ask you to confirm before installation. If you’re new to extensions, Google’s support pages outline standard steps and expectations for adding, managing, and troubleshooting extensions in Chrome.

- Open the extension’s official page on the Chrome Web Store.
- Select Add to Chrome, then confirm when prompted.
- Wait for the Add button to change to Remove from Chrome (or a similar state), which indicates installation.
- Optional: Pin the extension in your toolbar from the Extensions menu to keep it visible.

If you’re new to Chrome extensions, see our step‑by‑step [guide to the Chrome Web Store and safe installation steps](/blog/chrome-web-store-guide) for additional context on permissions, updates, and removal.

## First‑run and everyday use
Once installed, Google Dictionary typically requires little configuration. Here are the two main ways to use it.

### 1) Double‑click to define
- Navigate to any standard web page with selectable text.
- Double‑click a single word. If the page allows regular text selection, you should see a small definition bubble appear near the word.
- Click outside the bubble (or press Esc) to dismiss it.

Tips and expectations:
- The feature may not work on pages opened before installation until you reload them. This is specifically called out on the extension’s Web Store listing.
- Some sites use custom text rendering (for example, within a canvas) or other scripts that can interfere with selection. If you can’t select the text normally, the pop‑up likely won’t appear.

### 2) Use the toolbar icon for manual lookups
- Click the extension’s icon in your Chrome toolbar.
- Type or paste a word into the field that appears.
- Review the definition in the drop‑down or panel.

This method is handy when double‑click selection is unreliable on a page or when you want to look up a word that’s not on the current site.

## Enable and review your lookup history
The Web Store listing notes an optional history of words you’ve looked up. If you prefer to keep track of terms for study or revisiting later, look for a history or “word list” option in the extension’s settings.

Where to check:
- Open the Extensions menu in Chrome and select Manage extensions.
- Find Google Dictionary (by Google), then open Details and look for an Options or Extension options link.
- Within the extension’s settings, look for a history or similar toggle. Exact labels can vary; the option may allow you to enable or disable storage of your lookups.

If you’re privacy‑conscious or on a shared computer, consider leaving history off. If you enable history, verify how it’s stored and managed in the extension’s options before relying on it.

## Translate words to your language
According to the Web Store listing, the pop‑up can translate foreign words to your language. Practically, this works much like a definition bubble:

- Double‑click a foreign word on a web page (or type it into the toolbar lookup).
- The pop‑up may show a translation rather than just an English definition, depending on your settings and the word’s language.

Behavior can vary by page and by how your Chrome language preferences are set. If you’re not seeing translations where you expect them, check the extension’s options for language preferences, then test again on a text‑selectable page.

## Known limitations you should factor in
A few constraints can make the extension appear “broken” when it’s actually restricted by Chrome or the site you’re on:

- Chrome Web Store and certain internal pages: Google’s support documentation explains that Chrome may disable extensions on specific pages (like the Chrome Web Store or internal chrome:// URLs). If you try to double‑click on those pages, the dictionary pop‑up won’t load.
- Open tabs after installation: Tabs that were already open when you installed the extension may need a reload before definitions appear. This is stated on the Web Store listing.
- Non‑selectable text: Text inside images, videos, or canvas‑rendered areas usually can’t be double‑clicked for a definition pop‑up.
- Interference from other extensions: Tools that also intercept double‑clicks, selections, or pop‑ups might conflict. Temporarily disable similar extensions to test.

## Troubleshooting when pop‑ups don’t appear
Work through these checks in order. They align with limitations and publisher notes from the extension’s listing and Chrome’s support materials.

1) Reload the page you’re reading
- If the tab was open before installation, reload it. Many first‑run issues clear immediately after a refresh.

2) Test on a plain article page
- Try a simple news article or documentation page with normal text selection. If it works there, the earlier page likely used a special layout that blocks selection.

3) Confirm the extension is active
- Open chrome://extensions and make sure Google Dictionary (by Google) is enabled. If it’s off, turn it on and test again.

4) Check where you’re testing
- If you’re on the Chrome Web Store or an internal browser page, definitions won’t appear because Chrome typically disables extensions there, per Google’s support documentation. Test on a regular website.

5) Try the toolbar lookup
- If double‑click isn’t working on a site, use the toolbar icon and type the word. This confirms whether the core definition service is functioning.

6) Rule out extension conflicts
- Temporarily disable other extensions that capture selections, translate pages, or add in‑page pop‑ups. Retest after each change.

7) Reinstall as a last resort
- Remove the extension from chrome://extensions and add it back from the official Web Store listing. Reopen a test page and reload it before trying again.

## Privacy and data considerations
The Web Store listing notes an optional word history. If you enable it, be mindful that this creates a record of the terms you look up in your browser profile. Consider work or shared‑device policies before turning it on, and periodically review the setting in the extension’s options.

## FAQ

### Does Google Dictionary work in every tab?
Not necessarily. Chrome may disable extensions on certain pages, such as the Chrome Web Store and internal settings pages, per Google’s support documentation. Test on a standard website if the pop‑up isn’t showing.

### Why do I need to reload pages after installing?
The extension’s Web Store listing notes that tabs opened before installation might need a reload for the double‑click pop‑up to initialize on that page.

### Can I keep a history of the words I look up?
According to the listing, there is an optional lookup history. You can look for this toggle in the extension’s options. If you prefer not to retain data, leave it disabled.

### Does it translate or only define words?
The listing indicates it can translate foreign words in the pop‑up. Actual behavior may depend on language settings and the page you’re on.

### What if the double‑click pop‑up conflicts with another tool?
Try the toolbar lookup as a workaround, then temporarily disable similar extensions to isolate the conflict.
