## What this guide covers
If you rely on Google Keep for quick capture, the Chrome extension is a fast way to save the current page, a highlighted quote, or an image into a note. This guide shows the most reliable capture methods and calls out an important change: notes created in the extension’s pop-up no longer save automatically, and editing now happens on the web at keep.google.com. These behaviors are reflected in Google’s current help content and product pages.

## The essentials: what the Keep Chrome extension can do today
According to Google’s help, the extension can save webpages, selected text, and images to a Keep note, and you can add a short note in the pop-up before saving. However, as of December 5, 2022, “notes created in the extension no longer save automatically,” and editing is directed to Keep on the web rather than inside the pop-up. See Google’s official guidance and the web app for details and the most current UI.

- Save a page: capture the page’s title and URL with an optional note.
- Save selected text: capture the quote and the source link.
- Save an image: capture the image with the page link.
- Add a short note in the pop-up, then explicitly save.
- Edit and organize the saved note at keep.google.com.

References: Google’s Help Center and the extension’s listing describe these capabilities and the autosave change.

## Install and set up
1) Install from the Chrome Web Store. Search “Google Keep Chrome Extension” and add it to Chrome from the official listing.
2) Sign in to Chrome with the same Google account you use for Keep. The extension saves to the active account.
3) (Optional) Pin the extension so its icon stays visible on the toolbar for quicker access.

## Reliable capture workflows
The most common capture scenarios work best with a clear, repeatable flow. The key is to click Done (or the equivalent Save action) in the pop-up before closing it.

### Save the current page with context
- Open the page you want to capture.
- Click the Google Keep extension icon.
- Add a brief note if helpful (e.g., why you saved the page).
- Click Done to save. To revise or organize further, open keep.google.com.

What gets saved: the page title, its URL, and any note you added.

### Save a selected quote
- Highlight the text you want.
- Right‑click and choose the Keep option, or click the extension icon with the text selected.
- Optionally add a brief note.
- Click Done to save.

What gets saved: the selected text and the page’s link so you can return to the source.

### Save an image from a page
- Right‑click the image.
- Choose the Keep option that saves the image (naming can vary slightly by version).
- Add a note if needed.
- Click Done to save.

What gets saved: the image and the page link.

## Decision guide: choose the right capture action
| Goal | How to capture in Chrome | What gets saved | Where to edit/organize further |
|---|---|---|---|
| Save the entire page for later | Click the Keep icon on the page, add a short note, then Done | Page title, URL, and your note | keep.google.com |
| Save a quote or snippet | Select text, then right‑click Keep option (or click the icon), add note, Done | The highlighted text plus source link | keep.google.com |
| Save a specific image | Right‑click the image, choose Keep option, add note, Done | The image and the page link | keep.google.com |
| Jot a quick scratch note (no page context) | Click the Keep icon, type a note, Done | A plain note in your Keep | keep.google.com |

Note on autosave: Google’s help indicates that notes created in the extension no longer save automatically; clicking Done (or its current equivalent) is required. Edits should be made in Keep on the web.

## Organize captured notes effectively
- Add a meaningful line in the pop-up so you’ll remember why you saved the item.
- After capture, open keep.google.com to adjust titles, add labels, pin or archive items, and manage reminders if you use them. Google’s help directs users to edit associated notes on the web.
- Consider a consistent label scheme (e.g., “To‑Read,” “Research,” “Recipes”) so clips are easy to filter later.

## Current limits and what to expect
- No pop-up autosave: Google’s help specifies that, since Dec 5, 2022, notes created in the extension no longer save automatically. You need to confirm the save action.
- Pop-up is for capture, not full editing: The help content directs editing to keep.google.com. Expect minimal editing in the extension itself.
- Page context vs. full content: Saving a page via the extension stores the title and URL with your note. It does not pull the full article text unless you explicitly select and save that text.
- Image capture is page-bound: Saved images include the page context. For further organization or changes, use the web app.
- Interface specifics can change: Google’s UI labels and menus may evolve. If an option moves, check the extension listing and Help Center for the latest steps.

## Troubleshooting common issues
- “My note disappeared when I closed the pop-up.”
  - Likely cause: The note wasn’t saved. Since the extension pop-up no longer autosaves, click Done before switching tabs or closing the window. Then confirm it appears at keep.google.com.

- “I don’t see my clip in Keep.”
  - Make sure you’re signed in to the same Google account in Chrome and in Keep on the web. Then refresh keep.google.com.

- “Right‑click options for Keep are missing.”
  - Try clicking the toolbar icon instead. If context‑menu items are still missing, restart Chrome or reinstall the extension from the official listing.

- “The extension worked, but I need to change labels, colors, or reminders.”
  - Open keep.google.com to edit and organize. Google’s help points users to the web app for editing associated notes.

## FAQ
- Does the Keep Chrome extension still autosave notes?
  - No. Google’s help notes that as of Dec 5, 2022, notes created in the extension no longer save automatically. Click Done (or the current save action) to commit the note.

- Can I fully edit a note inside the extension pop-up?
  - The pop-up is designed for capture. For editing and organization, open keep.google.com.

- Will the extension save the whole article text automatically?
  - Not by default. It saves the page link and any text you explicitly select and save.

- How do I continue editing a clip I just saved?
  - Open keep.google.com. That’s where Google directs users to edit associated notes.
