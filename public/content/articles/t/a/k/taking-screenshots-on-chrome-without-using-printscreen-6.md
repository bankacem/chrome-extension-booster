## Keyboard Shortcuts for Screenshots

![Taking Screenshots On Chrome Without Using Printscreen 6 Overview](/content/images/taking-screenshots-on-chrome-without-using-printscreen-6/taking-screenshots-on-chrome-without-using-printscreen-6-overview.webp "Taking Screenshots On Chrome Without Using Printscreen 6 Overview")


In addition to using Chrome extensions, you can also use keyboard shortcuts to take screenshots on Chrome. The following shortcuts can be used to capture screenshots:

1. Ctrl + PrintScreen (Windows): Captures the entire screen and copies it to the clipboard.
2. Cmd + Shift + 4 (Mac): Captures a selected area of the screen and saves it to the desktop.
3. Ctrl + Shift + I (Windows) or Cmd + Shift + I (Mac): Opens the Chrome DevTools, which allows you to capture screenshots of web pages.

### Using Keyboard Shortcuts with Chrome Extensions

Combining keyboard shortcuts with Chrome extensions can enhance your screenshot-taking experience. For example, you can use the [Quick Screenshot Lite](/extension/quick-screenshot-lite) extension with the Ctrl + PrintScreen shortcut to capture full-page screenshots instantly.
