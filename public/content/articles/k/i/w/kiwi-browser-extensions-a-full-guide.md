## How to Install Kiwi Browser Extensions

![Kiwi Browser Extensions A Full Guide Overview](/content/images/kiwi-browser-extensions-a-full-guide/kiwi-browser-extensions-a-full-guide-overview.webp "Kiwi Browser Extensions A Full Guide Overview")


Installing Kiwi Browser extensions is a straightforward process. To get started, follow these steps:

- Open the Kiwi Browser on your mobile device
- Tap the three dots in the top-right corner of the screen
- Select "Extensions" from the dropdown menu
- Browse the available extensions and select the one you want to install
- Tap "Add to browser" to install the extension

Once you've installed an extension, you can manage it from the extensions menu. From here, you can enable or disable the extension, as well as access its settings.
