## How to Add Extensions to Chrome (Desktop)

Adding an extension is a simple 3-step process. Here is how to do it on Windows, Mac, or Linux:

### Step 1: Visit the Chrome Web Store
Open your Chrome browser and head to the [Chrome Web Store](https://chromewebstore.google.com). This is the official and safest marketplace for extensions.

### Step 2: Search and Select
Use the search bar in the top-left corner to find a tool. For example, search for "screenshot."
*   **Pro Tip:** Look for the **"Featured"** badge or a high number of reviews (4+ stars) before clicking.

### Step 3: Add to Chrome
1.  Click on the extension's name to open its detail page.
2.  Click the blue **"Add to Chrome"** button.
3.  A pop-up will appear asking for permissions. Review them and click **"Add extension."**

**That’s it!** The extension icon will now appear in your toolbar (often hidden behind the "Puzzle Piece" icon).

## How to Manage Your Extensions

Once you know how to add extensions to Chrome, you need to know how to keep them organized.

*   **Pinning Extensions:** Click the **Puzzle Piece icon** next to your profile picture. Click the **Pin icon** next to the extensions you use most often so they stay visible on your toolbar.
*   **The Manager Page:** Type `chrome://extensions` in your address bar to see a full list of everything you've installed. Here you can toggle extensions on/off or remove them entirely.
*   **Keyboard Shortcuts:** You can set custom keys to trigger extensions. Go to the manager page, click the **Hamburger menu (☰)** on the left, and select **Keyboard shortcuts.**

## Safety First: 3 Rules for Installing Extensions

Not all extensions are created equal. Because extensions have access to your browsing data, you must be careful. Follow these three rules:

1.  **The Rule of Least Privilege:** If a "Calculator" extension asks to "Read and change all your data on all websites," **do not install it.** It doesn't need that access to do its job.
2.  **Check the "Updated" Date:** Scroll to the bottom of the Web Store page. If an extension hasn't been updated in over 12 months, it is "abandoned software" and could have security holes.
3.  **Avoid "Off-Store" Installs:** Never install an extension by dragging a `.crx` file into your browser from a random website. This is the #1 way users get malware.

## FAQ: Frequently Asked Questions

### Can I add extensions to Chrome on Android or iPhone?
Officially, no. The standard Chrome app on mobile does not support extensions. However, you can use the **Kiwi Browser** or **Yandex Browser** on Android, which are built on Chromium and allow you to install extensions from the Chrome Web Store.

### Do extensions slow down my computer?
Yes, every extension you add uses a small amount of memory (RAM). If you have 20+ extensions, your browser will be slower.
*   **Solution:** Use the [ProTab Suspender](/extension/protab-suspender) extension to manage the memory usage of your tabs and keep Chrome fast.

### Are Chrome extensions free?
Most are free, but some use a "freemium" model where basic features are free and advanced ones require a subscription. Always check the "Privacy practices" tab on the Web Store to see if they sell your data.

### How do I delete an extension?
Right-click the extension icon in your toolbar and select **"Remove from Chrome."** You can also do this from the `chrome://extensions` page.
