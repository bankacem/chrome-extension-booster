## 1. Machine ID Slugs (234 articles)

These were generated by an older version of the AI Generator that appended a random `mm[random]` or `ml[random]` suffix to prevent collisions. The suffixes make URLs ugly and non-SEO-friendly but are already indexed.

**Examples:**
```
is-ghostery-safe-to-use-a-professional-2026-review-mmb7srbz193
adblock-chrome-android-complete-guide-2026-mmb7ltlowx4
best-chrome-extensions-for-privacy-2026-protect-your-online-identity-mll9br233zj
chrome-extensions-on-android-2026-kiwi-vs-yandex-vs-lemur-full-guide-ml3f6b
```

**Pattern analysis:**
- `-mm[a-z0-9]{6-15}` — most common (from batch run 1)
- `-ml[a-z0-9]{4-10}` — second pattern (from batch run 2)
- `-m[a-z0-9]{3-6}` — short variant

**Why these cannot be changed:**
1. Any indexed page with backlinks would lose all link equity
2. `window.history.replaceState` in BlogPost.tsx only cleans the browser URL — it does NOT send 301 to Googlebot
3. Even with a redirect, Google may take 3-6 months to process the URL change
4. The correct canonical is already set to the machine-ID slug itself

**Monitoring plan:** Check Google Search Console monthly. If machine-ID URLs are ranking, they are assets, not liabilities. If new machine-ID URLs appear (from new content generation), the AIGenerator fix prevents this.

## 2. Numeric Variant Slugs (147 articles)

Pattern: `{base-slug}-{1-15}`

These were generated when the same keyword was used multiple times, creating numbered variants. Examples:
```
screenshot-tool-chrome-guide-1
screenshot-tool-chrome-guide-9
full-page-screenshot-chrome-guide-9
quick-screenshot-chrome-tutorial-1
youtube-dark-mode-1
```

**Analysis:**
- Numbers indicate batch-generation runs, not article order
- Numbers 1-3 appear most frequently; numbers 8-15 are rarer
- These are the "cannibalization cluster" articles (see CANNIBALIZATION_REPORT.md)
- The numeric slugs are NOT clean SEO URLs but ARE crawlable

**Action:** These stay as-is. Merge decisions should be made per cluster (see CANNIBALIZATION_REPORT.md), with redirects after editorial review.

## 4. French Language Slugs (26 articles)

The AI Generator supports French, which produced 26 French-language articles. These are mixed into an English-language site without `hreflang` annotation. Examples:

```
comment-ajouter-une-extension-chrome-sur-android-facilement
comment-telecharger-des-videos-youtube-gratuitement
guide-complet-les-meilleures-extensions-chrome-2026
bloquer-les-publicites-sur-chrome-android
```

**Risks:**
- Google may classify these as a different language site segment
- No `hreflang` means Google can't serve them to French users appropriately
- Mixed-language site can confuse category crawling

**Options:**
1. `noindex` all French articles (aggressive — loses any French traffic)
2. Add `<html lang="fr">` detection per article and `hreflang` tags (complex)
3. Leave as-is and monitor (current default — low priority)

**Recommendation:** Leave as-is for now. If any French articles rank, add proper hreflang. If zero French traffic, noindex them during Phase 3 editorial cleanup.

## 8. Slug Generator — Current State

**`src/utils/slug.ts` — current behavior:**

```typescript
// Strips legacy mm/ml/m suffixes from OLD slugs
export function cleanSlug(input: string, maxLength = 80): string {
  return input
    .normalize("NFKD")                    // decompose accented chars
    .replace(/[\u0300-\u036f]/g, "")      // strip diacritics
    .toLowerCase()
    .replace(/[^a-z0-9]+/g, "-")          // non-alphanumeric → hyphen
    .replace(/-+/g, "-")                  // collapse consecutive hyphens
    .replace(/^-|-$/g, "")               // trim hyphens
    .slice(0, maxLength);                  // enforce max length
}

// Only called on ACTUAL collision detected in database
export function withCollisionSuffix(slug: string): string {
  return `${slug}-${Math.random().toString(36).slice(2, 6)}`; // 4-char random
}
```

**Assessment:** The generator is correct for new articles. Future slugs will be:
- Up to 80 characters
- Lowercase kebab-case
- No machine IDs unless genuine slug collision exists
