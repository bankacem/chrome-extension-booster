# Why Does Chrome Keep Redirecting? (Causes & Fixes 2026)

**Quick Answer:** Chrome keeps redirecting because of one of four causes: a malicious extension, adware/malware on your PC, a hijacked search engine setting, or aggressive redirect scripts on certain websites. Fix all four by following the steps below.

## The 4 Causes of Chrome Redirects {#causes}

### Cause 1: Malicious Extension
The most common cause. A free software installer "bundled" an extension you didn't notice. That extension now redirects your searches or injects ads.

### Cause 2: Changed Search Engine
Malware or unwanted software changes Chrome's default search engine to a fake one that shows ads and redirects every search.

### Cause 3: Adware/Malware on Your Computer
Software installed outside Chrome (often bundled with free downloads) modifies how your browser behaves at a system level.

### Cause 4: Aggressive Website Scripts
Some websites use JavaScript to redirect visitors to affiliate pages or ad networks. This isn't malware — it's just a poorly behaved website.

## Fix 1: Remove Malicious Extensions {#extensions}

1. Go to `chrome://extensions`
2. Review every extension installed
3. Remove anything you don't recognize or use
4. Restart Chrome

If you see extensions you didn't install — especially ones with names like "Search Manager," "QuickSearch," "PDF Converter Pro," "Shopping Assistant" — remove them immediately.

---

## Fix 2: Restore Your Search Engine {#search}

1. Chrome → Settings → **Search engine**
2. Click **"Manage search engines and site search"**
3. Remove any search engines you don't recognize
4. Set **Google** (or your preferred engine) as default
5. Check the address bar behavior — it should now use your chosen engine

Also check startup pages:
- Chrome Settings → **On startup**
- If it's set to a specific page you don't recognize, change to "Open the New Tab page"

## Fix 3: Remove Adware from Windows {#adware}

**Using Chrome's built-in cleaner:**
1. Chrome Settings → **Reset and clean up → Clean up computer**
2. Click **Find** → Remove anything detected

**Using Malwarebytes (free):**
1. Download **Malwarebytes Free** from malwarebytes.com
2. Run a full scan
3. Remove all detected threats
4. Restart your computer

---

## Fix 4: Reset Chrome Completely {#reset}

If the above fixes don't work, reset Chrome to factory settings:

1. Chrome Settings → **Reset and clean up**
2. Click **"Restore settings to their original defaults"**
3. Click **"Reset settings"**

This resets extensions, homepage, search engine, and pinned tabs. Your bookmarks and passwords are preserved.

## Prevent Future Redirects {#prevent}

- Install **uBlock Origin** — blocks redirect scripts proactively
- Only download software from official sources
- When installing free software, choose "Custom install" and deselect any bundled extras
- Enable **Enhanced Safe Browsing** in Chrome Security settings
- Audit your extensions monthly at `chrome://extensions`

## FAQ {#faq}

**Why does my Chrome redirect to a Russian or Chinese website?**
This is a common symptom of browser hijacking malware. Run Malwarebytes and reset Chrome settings immediately.

**Can Chrome redirects steal my passwords?**
If the redirect takes you to a phishing site mimicking a real login page and you enter credentials, yes. Always check the URL before logging in.

**Does reinstalling Chrome fix redirects?**
Sometimes. But if the malware is at the system level, it will re-infect Chrome after reinstall. Run Malwarebytes first, then reinstall if needed.

**Why do redirects happen only on some websites?**
The website is using redirect scripts for advertising or affiliate tracking. This is a site-level behavior, not a Chrome infection. uBlock Origin can block these.
