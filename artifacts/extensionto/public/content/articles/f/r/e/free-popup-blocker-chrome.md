# Best Free Popup Blocker for Chrome 2026 (Built-in + Extensions)

Chrome has a built-in popup blocker that most people don't know is underconfighed — and it misses the popup types that actually annoy users most. This guide covers all free options from the built-in setting to specific extension combinations that block overlays, cookie banners, and subscription popups that Chrome's native blocker lets through.

---

## What Chrome's Built-in Blocker Stops (And What It Misses)

**Chrome blocks:** New windows and new tabs opened by JavaScript (classic popups).

**Chrome doesn't block:**
- Overlay divs (newsletter signup boxes that dim the page)
- Cookie consent banners
- Anti-adblock dialogs
- Push notification request dialogs
- Sticky headers that cover content
- Countdown overlays ("You'll be redirected in 5 seconds")

Most modern "popups" are actually overlays — they're injected into the same page, not new windows. Chrome's built-in blocker can't touch them.

---

## Step 1: Enable and Configure Chrome's Built-in Blocker (Free, Always)

First, verify Chrome's popup blocker is actually enabled:

1. Chrome → Settings → Privacy and security → Site Settings
2. Click **"Pop-ups and redirects"**
3. Select **"Don't allow sites to send pop-ups or use redirects"**

Also block notification popups (separate setting):
1. Site Settings → **Notifications**
2. Select **"Don't allow sites to send notifications"**

These two settings cost nothing and stop new-window popups and notification dialogs.

## Step 2: Free Extensions for Overlay Popups

For the overlay-type popups Chrome misses, add one of these free extensions:

### uBlock Origin Lite — Best for Overlay Removal

uBlock Origin Lite's Annoyances filter list specifically targets overlay popups, cookie consent dialogs, newsletter signup boxes, and push notification prompts.

**Setup:**
1. Install uBlock Origin Lite → Open dashboard
2. Filter lists → enable: **"uBlock filters — Annoyances"**
3. Also enable: **"EasyList Cookie"** (removes cookie consent overlays)
4. Apply changes → Update now

This single configuration removes most overlay popups across the web automatically.

**Cost:** Free. No account required.

### Popup Blocker (Strict)

A lightweight extension focused specifically on popup blocking — including popups that bypass Chrome's built-in blocker. Install and forget, no configuration needed.

**Cost:** Free.
**RAM:** ~10MB idle.

## Free Built-in Alternative: Chrome's "Block" Permission Per Site

For sites that consistently show intrusive popups:

1. Visit the site
2. Click the **lock icon** in the address bar
3. Site settings → Pop-ups and redirects → **Block**

Per-site blocking overrides any permissions the site previously granted itself.

## Cookie Banner Removal (Free)

Cookie consent banners are technically not "popups" but they block content and work the same way. Free options:

**I Don't Care About Cookies** (Chrome Web Store) — removes cookie consent dialogs automatically. Free.

**uBlock Origin Lite + EasyList Cookie** — same result if you already have uBlock configured.

## FAQ

**Does Chrome's popup blocker block all types of popups?**
No — only new window/tab popups. Overlay-style popups that appear within the page require an ad blocker with annoyance filters.

**Will these free options block push notification requests?**
Yes — enabling "Don't allow sites to send notifications" in Chrome settings stops notification request dialogs. uBlock Lite's Annoyances filter also neutralizes sites that use JavaScript to re-trigger the request.

**Are paid popup blockers better than these free options?**
Generally not. The free options described above are as effective as any paid popup blocker for standard use cases.
