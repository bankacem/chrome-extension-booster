# How to Install IDM Extension in Chrome (2026)

**Quick Answer:** Internet Download Manager (IDM) installs its Chrome extension automatically when you install IDM on Windows. If the extension is missing, go to Chrome's Extensions page and enable it manually, or reinstall it from IDM's settings.

## What Is IDM? {#what}

Internet Download Manager (IDM) is a Windows application that accelerates downloads by splitting files into segments and downloading them simultaneously. It integrates with Chrome via a browser extension that captures download links automatically.

IDM is **Windows only** — it does not work on Mac or Linux.

---

## How to Install IDM Extension in Chrome {#install}

**Prerequisites:** IDM must be installed on your Windows PC first. Download from [internetdownloadmanager.com](https://www.internetdownloadmanager.com).

**Automatic installation:**
1. Install IDM on your PC
2. Open Chrome — IDM usually installs its extension automatically
3. A prompt may appear asking you to confirm — click **"Add extension"**
4. The IDM icon appears in your Chrome toolbar

**If the extension doesn't install automatically:**
1. Open IDM → Go to **Options** → **General** tab
2. Click **"IDM download bar and IDM extension settings for browsers"**
3. Click **"Install Chrome Extension"**

## Fix: IDM Extension Not Working in Chrome {#fix}

**Problem 1: Chrome blocked the extension**
Chrome sometimes blocks extensions not from the Web Store.

Fix:
1. Go to `chrome://extensions`
2. Find IDM Integration Module
3. If disabled, click the toggle to enable it
4. If missing, see manual install steps below

**Problem 2: Extension installed but no download bar appears**
1. Right-click the IDM toolbar icon → **Options**
2. Make sure "Use IDM download bar on videos" is checked

**Problem 3: IDM not capturing downloads**
1. Check that IDM is running in the system tray (bottom right of Windows taskbar)
2. Right-click the tray icon → **Start IDM**

## How to Enable IDM Extension Manually {#manual}

If Chrome shows a warning about the IDM extension being unverified:

1. Go to `chrome://extensions`
2. Enable **Developer mode** (toggle in top right)
3. Click **"Load unpacked"**
4. Navigate to your IDM installation folder (usually `C:\Program Files (x86)\Internet Download Manager`)
5. Find the **IDMGCExt** folder and select it
6. The extension loads and appears in Chrome

## FAQ {#faq}

**Why did Chrome disable my IDM extension?**
Chrome periodically disables extensions not installed from the Chrome Web Store. This is a security measure. Re-enable it via `chrome://extensions`.

**Does IDM work on Mac?**
No. IDM is Windows-only. Mac users should try Folx or Downie.

**Is IDM free?**
IDM offers a 30-day free trial. A lifetime license costs approximately $25.

**Can IDM download from YouTube?**
IDM can capture some streaming video URLs, but YouTube actively blocks this. yt-dlp is more reliable for YouTube downloads.
