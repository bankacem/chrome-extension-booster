# How to Take a Screenshot in Chrome (5 Methods 2026)

**Quick Answer:** Press **Ctrl+Shift+P** in Chrome DevTools and type "screenshot" for instant full-page or visible-area captures with no extension needed. For a dedicated button in your toolbar, install GoFullPage or Awesome Screenshot.

## Method 1: Chrome DevTools Built-in (No Extension) {#devtools}

Chrome has a hidden built-in screenshot tool inside Developer Tools. No extension needed.

**For full-page screenshot:**
1. Open the page you want to capture
2. Press **F12** (or Ctrl+Shift+I) to open DevTools
3. Press **Ctrl+Shift+P** to open the command palette
4. Type **"screenshot"**
5. Select **"Capture full size screenshot"**
6. The PNG downloads automatically to your Downloads folder

**Other options in the same menu:**
- **Capture screenshot** — visible area only
- **Capture node screenshot** — a specific HTML element
- **Capture area screenshot** — drag to select a region

## Method 2: GoFullPage Extension {#gofullpage}

GoFullPage is the most popular full-page screenshot extension with 2M+ users.

1. Install **GoFullPage** from the Chrome Web Store
2. Navigate to any page
3. Click the GoFullPage icon in your toolbar
4. It scrolls through the page and stitches a full screenshot
5. Download as PNG or PDF

**Pros:** Simple, reliable, captures lazy-loaded images
**Cons:** Freemium — editing features require a paid plan

## Method 3: Awesome Screenshot {#awesome}

Awesome Screenshot offers screenshot + screen recording in one extension.

**Screenshot features:**
- Capture visible area, selected area, or full page
- Annotate with arrows, text, shapes
- Blur sensitive areas before sharing
- Share via link or download

1. Install **Awesome Screenshot & Screen Recorder**
2. Click the icon → choose capture type
3. Annotate if needed → Download or copy to clipboard

## Method 4: Nimbus Screenshot {#nimbus}

Nimbus Screenshot focuses on professional annotation and team collaboration.

**Unique features:**
- Capture scrollable pages
- Record screen with audio
- Upload to Nimbus Note workspace
- Add timestamps to annotations

Best for: teams doing QA testing, bug reporting, or documentation.

## Method 5: Operating System Shortcuts {#os}

These capture what's visible on screen without Chrome-specific features:

| OS | Shortcut | Captures |
|----|----------|----------|
| Windows | Win+Shift+S | Selected region (clipboard) |
| Windows | Print Screen | Full screen |
| Mac | Cmd+Shift+4 | Selected region |
| Mac | Cmd+Shift+3 | Full screen |
| Mac | Cmd+Shift+5 | Screen recording options |

**Limitation:** OS shortcuts can't capture below-the-fold page content.

## FAQ {#faq}

**How do I take a full-page screenshot in Chrome without an extension?**
Use Chrome DevTools: F12 → Ctrl+Shift+P → type "screenshot" → "Capture full size screenshot."

**Can Chrome screenshot PDFs?**
Yes. Use GoFullPage or the DevTools method on a PDF opened in Chrome.

**How do I screenshot a specific element on a page?**
DevTools → Ctrl+Shift+P → "Capture node screenshot" → click the element you want.

**What's the best screenshot extension for sharing with a team?**
Nimbus Screenshot for annotation and team sharing. Awesome Screenshot for simpler needs.
