# How to Block Popups on Chrome Android (2026)

**Quick Answer:** Go to **Chrome Settings → Site Settings → Pop-ups and redirects → Block**. This stops most popups. For aggressive popup sites, add them to Chrome's block list individually.

## Block All Popups in Chrome Android Settings {#settings}

Chrome for Android has a built-in popup blocker that is sometimes disabled by default.

**Steps:**

1. Open **Chrome** on your Android device
2. Tap the **three-dot menu** (top right)
3. Go to **Settings**
4. Scroll down and tap **Site settings**
5. Tap **Pop-ups and redirects**
6. Toggle it to **Blocked**

This blocks most popups across all websites immediately. No extension needed.

---

## Block Popups on Specific Sites {#specific}

If a specific site keeps showing popups despite the global block:

1. Visit the site in Chrome
2. Tap the **lock icon** or **info icon** in the address bar
3. Tap **Site settings**
4. Find **Pop-ups and redirects**
5. Change to **Block**

This adds a site-specific rule that overrides any previously granted permissions.

## Block Notification Popups {#notifications}

Many sites ask for notification permission — then spam you with popups through the notification system. To block these:

1. Go to **Chrome Settings → Site settings → Notifications**
2. Toggle to **Block**

Or block notifications from a specific site:
1. Visit the site
2. Tap the info icon → Site settings → Notifications → Block

**To revoke already-granted notification permissions:**
1. Go to **Settings → Site settings → Notifications**
2. Under "Allowed," tap any site
3. Tap **Block**

## Use Kiwi Browser with uBlock Origin {#kiwi}

For the most aggressive popup blocking on Android — including popups that bypass Chrome's built-in blocker — use **Kiwi Browser** with **uBlock Origin** installed.

1. Install **Kiwi Browser** from the Play Store
2. Open Kiwi → Menu → Extensions → Add from store
3. Install **uBlock Origin**
4. Enable it

uBlock Origin blocks popups, redirects, and overlay ads that Chrome's built-in blocker misses entirely.

## FAQ {#faq}

**Why does Chrome still show popups even after blocking them?**
Some sites use JavaScript tricks to trigger popups that bypass Chrome's filter. Use Kiwi Browser + uBlock Origin for these cases.

**Does blocking popups break websites?**
Rarely. Some legitimate sites use popups for cookie consent or login dialogs. If a site breaks, allow popups for that specific site only.

**Why am I getting popups even when Chrome is closed?**
These come from notifications you previously allowed. Go to Chrome Settings → Site settings → Notifications and revoke all permissions.
