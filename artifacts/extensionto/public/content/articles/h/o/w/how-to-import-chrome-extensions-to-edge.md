# How to Import Chrome Extensions to Edge (2026)

**Quick Answer:** Microsoft Edge supports Chrome extensions natively. Go to **Edge Settings → Extensions → Allow extensions from other stores**, then visit the Chrome Web Store and install any extension directly into Edge.

## Why Chrome Extensions Work in Edge {#why}

Microsoft Edge is built on **Chromium** — the same open-source engine as Google Chrome. Since they share the same extension architecture, Chrome Web Store extensions are fully compatible with Edge.

Microsoft officially supports this and even has a setting to enable it.

---

## Method 1: Install from Chrome Web Store (Recommended) {#chromestore}

1. Open **Microsoft Edge**
2. Click the **three-dot menu (...)** → **Extensions**
3. Click **"Allow extensions from other stores"** (toggle at the bottom left)
4. Confirm by clicking **Allow**
5. Now navigate to [chrome.google.com/webstore](https://chrome.google.com/webstore)
6. Find any extension and click **"Add to Chrome"**
7. Edge will ask: **"Add extension to Microsoft Edge?"** — click **Add extension**

The extension installs in Edge exactly as it would in Chrome.

---

## Method 2: Import Chrome Extensions Automatically {#import}

When you first set up Edge, it offers to import data from Chrome — including extensions.

1. Open Edge → **Settings → Profiles → Import browser data**
2. Select **"Google Chrome"** as the source browser
3. Check **"Extensions"**
4. Click **Import**

Note: Edge will attempt to find the same extensions in either the Edge Add-ons store or Chrome Web Store. Some extensions may need manual re-installation if they're not found automatically.

---

## Method 3: Load Unpacked Extension {#unpacked}

For developer versions or extensions not on any store:

1. Edge → **Extensions → Manage extensions**
2. Enable **Developer mode** (toggle, top right)
3. Click **"Load unpacked"**
4. Navigate to the extension folder on your PC and select it

## FAQ {#faq}

**Is it safe to install Chrome extensions in Edge?**
Yes. The same security considerations apply as in Chrome — install from trusted publishers with high user counts.

**Does importing Chrome extensions also move my settings and data?**
No. Extension settings (like your uBlock Origin filter lists) are not imported. You'll need to reconfigure extensions after installing them in Edge.

**Can I sync Edge extensions with Chrome?**
No. Edge syncs extensions across Edge browsers via your Microsoft account. Chrome syncs via your Google account. The two ecosystems are separate.

**Why does Edge have its own extension store if it supports Chrome extensions?**
The Edge Add-ons store is Microsoft's curated marketplace. Some publishers release Edge-specific versions there. But the Chrome Web Store gives access to far more extensions.
