# How to Install uBlock Origin on Chrome Android (2026)

**Quick Answer:** uBlock Origin cannot be installed on official Chrome for Android. To use uBlock Origin on Android, install **Kiwi Browser** (free, Chromium-based) and then install uBlock Origin from the Chrome Web Store within Kiwi.

## Why uBlock Origin Doesn't Work on Chrome Android {#why}

Chrome for Android doesn't support browser extensions — at all. Google disabled extension support in Chrome for Android in 2012 and has not re-enabled it. uBlock Origin, like all Chrome extensions, cannot be installed on the official Chrome app.

The solution: use a different browser that supports extensions.

---

## Step 1: Install Kiwi Browser {#kiwi-install}

1. Open the **Google Play Store** on your Android device
2. Search for **"Kiwi Browser — Fast & Quiet"**
3. Tap **Install**
4. Open Kiwi Browser after installation

Kiwi Browser is a free, open-source Chromium-based browser that specifically enables Chrome Web Store extension support on Android.

---

## Step 2: Install uBlock Origin in Kiwi {#ublock-install}

1. In Kiwi Browser, tap the **⋮ menu** (top right corner)
2. Tap **Extensions**
3. Tap **"+ (from store)"** — this opens the Chrome Web Store
4. In the search bar, type **"uBlock Origin"**
5. Find the extension by **Raymond Hill** (the official one, 40M+ users)
6. Tap **"Add to Chrome"**
7. Tap **"Add extension"** to confirm permissions

uBlock Origin is now installed in Kiwi Browser and will block ads and trackers on all websites.

---

## Step 3: Configure uBlock Origin {#configure}

uBlock Origin works immediately after installation with no configuration required. But for better blocking:

**Enable extra filter lists:**
1. Tap the uBlock Origin icon (in Kiwi's extension bar at bottom)
2. Tap the **gear icon** (Open the dashboard)
3. Go to **Filter lists**
4. Enable additional lists:
   - **EasyList** ✅ (usually already enabled)
   - **EasyPrivacy** ✅
   - **Online Malicious URL Blocklist** ✅
   - **uBlock filters — Annoyances** ✅
5. Tap **"Update now"**

---

## Test That It's Working {#test}

1. Open YouTube in Kiwi Browser
2. Play any video — pre-roll ads should not appear
3. Visit any news site — banner ads should be gone
4. The uBlock Origin icon shows a number indicating blocked elements

If ads still appear, tap the uBlock icon and tap **"Update now"** to refresh filter lists.

---

## Alternative: Firefox for Android {#firefox}

Firefox for Android natively supports extensions — no third-party browser needed.

1. Install **Firefox** from the Play Store
2. Open Firefox → Settings → Extensions (or visit addons.mozilla.org)
3. Search for **uBlock Origin** and install it

Firefox's uBlock Origin is the same extension with identical functionality. This is a good alternative if you prefer Firefox's privacy features.

## FAQ {#faq}

**Does uBlock Origin block ads in all apps on Android?**
No. uBlock Origin in Kiwi/Firefox only blocks ads within those browsers. It does not affect other apps like YouTube app, Instagram, or games. For system-wide ad blocking on Android, use **AdGuard for Android** or enable private DNS with a block list.

**Will uBlock Origin block YouTube ads in Kiwi Browser?**
Yes. YouTube ads are blocked in Kiwi Browser with uBlock Origin, just like on desktop Chrome.

**Is Kiwi Browser slower than Chrome?**
Comparable speed. With uBlock Origin blocking ad scripts, many pages actually load faster in Kiwi than in Chrome.

**Can I sync uBlock Origin settings between desktop and Kiwi?**
uBlock Origin settings can be exported from desktop (dashboard → Settings → Backup to file) and imported in Kiwi (same method).
