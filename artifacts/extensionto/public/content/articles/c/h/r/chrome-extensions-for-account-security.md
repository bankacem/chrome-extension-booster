## Layer 1: Password Security

### Bitwarden (Free)
The foundation of account security. Bitwarden generates strong unique passwords for every account, stores them encrypted with AES-256 + Argon2id, and autofills only on the correct domain — providing built-in phishing resistance.

**Key account security features:**
- Password generator (custom length, character sets)
- Duplicate password detection
- Weak password alerts
- Domain-matched autofill (refuses to autofill on phishing domains)
- Passkey storage (for passwordless login)

## Layer 2: Phishing and Malware Blocking

### Malwarebytes Browser Guard (Free)
Blocks phishing pages, malicious download links, and fake tech support scams in real time. Catches threats up to 4 hours before Chrome's Safe Browsing database updates.

### uBlock Origin Lite (Free)
Blocks malvertising — ads on legitimate sites that link to phishing pages or trigger drive-by malware downloads. A secondary but important phishing prevention layer.

## Layer 3: Breach Monitoring

### Bitwarden Premium ($10/year)
Includes integrated breach monitoring via Have I Been Pwned. Alerts you when any saved credential appears in a known breach.

### Free alternative: Have I Been Pwned monitoring
Set up free email breach alerts at `haveibeenpwned.com/NotifyMe` — no extension required.

## Layer 4: Tracker and Data Exposure Reduction

### Privacy Badger (Free)
Blocks cross-site trackers that build behavioral profiles used in targeted social engineering attacks. Reduces the data attackers can gather about you before a targeted phishing attempt.

### ClearURLs (Free)
Removes tracking parameters from URLs. Prevents advertisers and data brokers from logging your click behavior across sites.

## FAQ

**Q: Is a password manager really necessary for account security?**
Yes — password reuse is the single biggest account security risk. A password manager makes it practical to use a unique 16+ character password for every account, which eliminates credential stuffing attacks entirely.

**Q: Should I use a browser-based 2FA extension or a separate app?**
A separate authenticator app (Aegis, Raivo, Google Authenticator) is safer than a browser-based 2FA extension. Browser extensions can be compromised; a dedicated app on your phone is isolated from browser-based attacks.

**Q: Does uBlock Origin protect accounts specifically?**
Indirectly — by blocking malvertising (malicious ads on legitimate sites), uBlock Origin prevents drive-by infections that could install credential-stealing malware.
