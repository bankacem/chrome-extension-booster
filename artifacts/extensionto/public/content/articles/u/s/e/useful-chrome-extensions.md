<section class="article-section" id="tips">
  <h2 class="section-head">🛡️ 7. How to Install Chrome Extensions Safely</h2>
  <p>Not all extensions are trustworthy. Follow these rules before installing any extension from the <a href="/blog/chrome-web-store-2" title="Chrome Web Store Guide">Chrome Web Store</a>:</p>

  <h3 class="sub-head">Check Before You Install</h3>
  <ul style="margin: 0 0 20px 22px; color: #2a2a35;">
    <li style="margin-bottom:10px"><strong>User count matters</strong> — Extensions with 100K+ users are generally safer than obscure ones.</li>
    <li style="margin-bottom:10px"><strong>Read the permissions</strong> — Be suspicious of any extension asking to "read data on all sites."</li>
    <li style="margin-bottom:10px"><strong>Check the last update date</strong> — Abandoned extensions are security risks.</li>
    <li style="margin-bottom:10px"><strong>Read negative reviews</strong> — Users report suspicious behavior there first.</li>
    <li style="margin-bottom:10px"><strong>Audit regularly</strong> — Visit chrome://extensions every month and remove what you don't use.</li>
  </ul>

  <div class="warn-box">
    <strong>⚠️ Red Flag:</strong> If a Chrome extension suddenly asks for additional permissions via an update, that's a warning sign. Compromised extensions have been sold to malicious buyers who then push updates that steal data.
  </div>
</section>
